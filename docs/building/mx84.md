# MX84 build status

The repository retains MX84 board-data, Vitesse initialization, overlay, static control binary, and post-build assets. A reproducible image target still requires:

- complete Buildroot configuration
- kernel source/configuration and device tree
- documented flash/container layout
- image assembly and validation
- hardware report

Run `make mx84-check` for the current inventory. The platform is marked **untested**, not unsupported.
