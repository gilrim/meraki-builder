# MX80 build

MX80 uses a separate PowerPC/Buildroot workflow retained from the board’s available source configuration and image assembler.

```sh
make mx80-check
make mx80-prepare
make mx80-menuconfig
make mx80
make mx80-validate MX80_IMAGE=/path/to/ubi_image.bin
```

The workspace is `.work/mx80`, downloads are retained there, and the published image is `artifacts/mx80/postmerkos-mx80.bin`.

The integrated path uses Buildroot 2020.02.8 and the configured Fullerene 3.4 kernel tarball. Validation checks the Meraki image magic, 0x400-byte header, payload size and SHA-1, DTB at 0x4000, kernel uImage at 0x20000, initramfs uImage at 0x400000, and container maximum.

This target is untested on hardware in this repository snapshot. Keep a complete recovery image and verify all source downloads before flashing.
